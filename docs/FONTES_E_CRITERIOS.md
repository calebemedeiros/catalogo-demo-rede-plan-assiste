# Critérios para configuração de fontes

O catálogo começa vazio. Uma fonte somente pode ser ativada quando possuir:

1. API pública documentada em HTTPS;
2. resposta JSON obtida por uma chamada direta;
3. vínculo direto ou indireto definido;
4. autorização institucional registrada;
5. mapeamento explícito dos campos públicos;
6. responsável e canal de correção conhecidos.

Não são aceitos scraping, credenciais, cookies, proxies, enumeração por letras ou identificadores, HTML, planilhas ou arquivos brutos. Respostas que não atendam ao contrato não são publicadas.
